## Описание

В данном проекте реализовано клиент-серверное ПО для публикации новостных заметок. Асинхронный сервер реализован с помощью библиотеки asio. Клиент и сервер обмениваются json-ами с использованием библиотеки nlohmann/json. Используется следующий формат json-ов:

Рукопожатие клиента:
```
{ "type": "HANDSHAKE", "client_id": "<id>" }
```
Рукопожатие сервера:
```
{ "type": "HANDSHAKE_ACK", "status": "success", "name": "<name>" }
```
Заметка:
```
{
  "type": "SUBMIT_NOTE",
  "note_id": <id>,
  "category": <category>,
  "topic": <topic>,
  "content": <content>
}
```
Ответ на заметку (status - "ACCEPTED" / "DUPLICATE" / "REJECTED"):
```
{
  "type": "RECEIPT",
  "note_id": <id>,
  "status": <status>
  "reason": <reason>
}
```
Ошибка:
```
{
  "type": "ERROR",
  "reason": <reason>
}
```

Состояние сервера сохраняется в базу данных в файле times_database.json. При каждом запуске сервер восстанавливает своё состояние из базы. После запуска сервера редактор может им управлять через cli - смотреть статистику, добавлять корреспондентов и менять их уроовень доверия. Клиент может смотреть свою статистику и отправлять заметки.

Сервер имеет объект класса Manager, который имеет список текущих сессий с клиентами. При попытке отправить сообщение отключившемуся клиенту оно кладётся в очередь менеджера. Содержимое очереди отправляется клиенту при следующем подключении.

## Компиляция и запуск

Компиляция:

```
cmake build
cmake ---build build
```

Запуск сервера:
```
./build/server
```

Запуск клиента (id - идентификатор репортёра):
```
./build/client 127.0.0.1 8080 <id>
```
